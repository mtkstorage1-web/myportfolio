# Minn Thant Ko — Portfolio

Clean minimalist personal portfolio with an interactive 7-project slide deck, directional `< — >` arrow animations, and bespoke graphic-motion stages.

**Live:** https://minnverse.netlify.app

## Stack
- React 19 + TypeScript (strict)
- Vite 6 + Tailwind CSS v4
- Motion (`motion/react`) + Lucide icons
- Self-hosted fonts (`Space Grotesk`, `Inter`, `JetBrains Mono`) for offline-ready rendering

## Run Locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
